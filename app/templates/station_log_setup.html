Station log setup required

The new station log tables have not all been created in RAMS's local database. This is separate from the RadioDJ MySQL/MariaDB connection.
{% if can('settings:edit') %}

You can configure the RadioDJ SQL connection and NAS archives before initializing the log.

On the RAMS server, run the following commands once. The initialization creates missing station log tables without replacing existing data.

cd /opt/RadioAdminSystem
sudo -u www-data env RAMS_WSGI_SAFE_MODE=1 RAMS_RUN_SCHEDULER_ON_STARTUP=0 /opt/RadioAdminSystem/venv/bin/python -m flask --app 'app:create_app()' station-log init-db
sudo systemctl restart apache2

These paths and the service account match WLMC's deployment. Adjust them if your installation uses a different directory, virtual environment, or WSGI account.
